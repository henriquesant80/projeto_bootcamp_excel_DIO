# Simulador de Investimentos em Fundos Imobiliários (FIIs)

## Descrição do Projeto
Este projeto consiste no desenvolvimento de uma ferramenta simples em Excel para simular investimentos em Fundos Imobiliários (FIIs). 

A planilha permite calcular:
* **Valor Total Investido:** Acompanhamento do aporte realizado pelo investidor.
* **Patrimônio Acumulado:** Evolução do patrimônio ao longo do tempo.
* **Dividendos Mensais:** Estimativa de renda passiva gerada pelos fundos.

O objetivo principal é ajudar o usuário a visualizar o impacto e o crescimento de seus investimentos no longo prazo. Este modelo foi pensado como uma solução prática e acessível para investidores iniciantes, podendo servir como base para futuras expansões e personalizações.

## Recursos e Funcionalidades do Excel Utilizados
* **Fórmulas e Funções:** Cálculos de juros compostos, acúmulo de patrimônio e proventos mensais, validação de dados.
* **Formatação Condicional:** Destaque para tipos de investidor.
* **Tabelas e Gráficos:** Visualização clara da distribuição do patrimônio entre os tipos de FII's.
* **Recursos:** Mesclagem de células, inserção de imagem, ocultação de linhas, grades, colunas e linhas não utilizadas.
